IREBRO BYGGSERVICE — WEBBFILPAKET

INNEHÅLL
- index.html: startsida med inbyggd CSS och JavaScript
- assets/: Irebro Byggservices logotyp och optimerade företagsbilder

VISA PÅ DATORN
Öppna index.html i en webbläsare. Bilderna laddas från assets-mappen, som ska ligga bredvid index.html.

LÄGG UPP PÅ INLEED
1. Packa upp webbpaketet.
2. Öppna den domän som redan finns i ditt Inleed-konto och gå till dess webbplatsmapp (vanligen public_html).
3. Lägg index.html direkt i mappen och ladda upp hela assets-mappen bredvid den.
4. Behåll filnamnen och mappstrukturen. Startsidan måste heta index.html.

Felmeddelandet “Domain exists on …” kommer från Inleeds/DirectAdmins domänkontroll och betyder att domänen redan känns igen i deras server- eller DNS-miljö. Lägg därför inte upp domänen som en ny dubblett. Om den inte syns i kontot, skicka hela felmeddelandet till Inleeds support och be dem kontrollera vilken server eller DNS-zon som redan har domänen.

MEJLKONTAKT
Mejlknappen öppnar besökarens e-postapp adresserad till info@irebrobyggservice.se. Besökaren skriver och skickar sitt mejl där.

BILDER
Bilder och logotyp hämtade från Irebro Byggservices officiella webbplats: https://irebrobyggservice.se/
